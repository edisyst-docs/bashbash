# zz - Sandbox

File usa-e-getta usati come materiale di prova negli esempi delle altre cartelle.
Non contengono appunti: servono solo ad avere qualcosa su cui lanciare i comandi.
Si possono sporcare, sovrascrivere e rigenerare senza problemi.

| File | Usato da |
|---|---|
| `divina_commedia.txt` | Esempi di `grep`, `sort`, `head`/`tail`, `less` |
| `file_5000.txt` | Esempi di `split`, `paste`, `wc`, `tail -f` |
| `file.txt`, `file-batch.txt` | Prove generiche di lettura/scrittura |
| `phonebook` | Esempi di `sort -k` e `uniq` |
| `link1` | Esempio di link simbolico |
| `simile1.sh`, `simile2.sh` | Coppia di file quasi identici, per `diff` e `comm` |
| `img.png`, `img_1.png` | File binari per gli esempi di `file` e `split -b` |
| `demo-script/` | `s.sh`, `s1.sh`, `s2.sh`, `s3.sh`: script minimi per provare i modi di lancio, il `source` e i parametri posizionali |
| `demo-script/eseguibili/` | `t.txt`, `tt.txt`: file di prova per permessi e redirezioni |
| `zz_esempi/` | Alberatura di cartelle e file vuoti per provare `find`, `tree` e `select` |
